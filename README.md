# Job Listings Scraper

A Python web scraper that extracts job listings from the Fake Python Jobs website and saves the data into a CSV file.

## Features

- Scrapes job listings from a public website
- Extracts job title
- Extracts company name
- Extracts job location
- Extracts job application URL
- Handles missing information
- Saves the results to a CSV file

## Technologies Used

- Python
- Requests
- BeautifulSoup
- CSV
